# Владимир Кунаев — психолог

Лендинг психолога: готовый сайт, дизайн-система и блоки для Тильды.

**Живая страница:** https://mas040500-debug.github.io/kunaev-psycholog/

**Сайт лежит в корне** — `index.html`, `styles.css`, `assets/`. Никакой сборки не нужно,
открывается двойным кликом. Это же делает репозиторий сразу пригодным для GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / `root`).

---

## Что внутри

| путь | что это |
|---|---|
| `index.html`, `styles.css`, `assets/` | **готовый сайт**, одна страница, 8 секций |
| `design-system/` | токены дизайн-системы: `tokens.css`, `tokens.json`, описание решений |
| `tilda-blocks/` | та же вёрстка, порезанная на блоки **T123** для Тильды |

Сайт и блоки Тильды — одна и та же вёрстка в двух упаковках. Правки вносятся в оба
места, либо выбирается что-то одно.

## Адаптив

Три брейкпоинта, ровно как в макетах Figma:

| | ширина | поле от края | заголовок героя |
|---|---|---|---|
| десктоп | 1440 | 128 | 64/72 |
| планшет | ≤1024 | 48 | 48/56 |
| мобильный | ≤767 | 16 | 32/40 |

Полная шкала типографики и обоснование каждого шага — в
[`design-system/README.md`](design-system/README.md).

Что перекладывается на узких экранах: меню уходит в бургер, ряды карточек становятся
колонками, фото в герое встаёт под текст, папка с дипломом — над текстом. Пунктирные
связи майндмапа в «Подходе» скрываются ниже 1200px: это нарисованные от руки кривые,
привязанные к позициям карточек, они не перетекают.

## Шрифты

**Arimo** — основной, подключён с Google Fonts. Полная кириллица.

**Good Vibes Pro** — рукописный акцент (строка в герое, водяной знак «комфорт», подпись
на фото и на бирке диплома). На Google Fonts его нет — самохостится из
`assets/fonts/GoodVibesPro.ttf` (кириллическая версия), `@font-face` в `styles.css`
подключает его напрямую.

**Great Vibes** в стеке ниже — не альтернатива, а страховка на случай, если `.ttf` не
подгрузится: у него есть кириллица, но метрики другие, строки в герое поедут. Именно
поэтому размер скрипта на планшете и мобильном подобран так, чтобы фраза «комфортных
условий» влезала в одну строку (56px и 28px) при любом из двух шрифтов: переносить её
нельзя — обе гарнитуры для этого узла недоступны для программного измерения ширины.

## Фотографии

`assets/portrait-hero.png` и `assets/portrait-about.png` выгружены из Figma в том
размере, в котором они там лежат (1:1 к макету). Для экранов с высокой плотностью
пикселей лучше положить оригиналы в двойном разрешении под теми же именами — вёрстку
менять не придётся.

`assets/docs/` — семь сканов настоящих дипломов и сертификатов Владимира: диплом МГУ,
переподготовка и повышение квалификации с приложениями, сертификат МГУ. Показываются
в карусели секции «Образование» — см. ниже.

## Карусель документов («Образование»)

Папка с кольцами, зажимом и загнутым углом собрана вёрсткой (CSS + inline SVG), а не
картинкой — так бумажка с подписью масштабируется вместе с папкой на любом экране.
Скан документа и подпись на бумажке («Диплом МГУ» / «Факультет психологии» и т. д.)
переключаются синхронно стрелками, без перезагрузки страницы — логика в конце
`index.html`, массив `docs` в скрипте карусели. Стрелки листают по кругу, следующие
сканы подгружаются заранее, чтобы переключение было без задержки.

Чтобы добавить или заменить документ: положить скан в `assets/docs/`, добавить/поменять
объект в массиве `docs` (`src`, `note`, `sub`, `alt`).

## Проверка

```sh
# сайт
open index.html          # или просто двойной клик

# блоки Тильды — склеить в одно превью
cd tilda-blocks && sh build-preview.sh
```

Мобильный вид удобнее смотреть через `tilda-blocks/_mobile.html`: окно браузера на
Windows нельзя сузить меньше ~500px, и обычный ресайз даёт обманчивую картину.
